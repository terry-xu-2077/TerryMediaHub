# TerryMediaHub 实施与验收清单

更新日期：2026-11-04。以下均为待实施、待验证，未勾选项目不代表已具备。

## 1. 阶段交付

| 阶段 | 交付内容 | 结束条件 |
|---|---|---|
| 兼容性与架构基线 | 配置样本、站点矩阵、JVM 构建、API/worker 契约、迁移骨架 | 样本可追踪，协议和代码边界明确 |
| 服务和播放闭环 | 四类解析、本地扫描、搜索、多线路、播放会话 | Web/TV 可使用相同 API 完成核心流程 |
| Web 完整体验 | 首页、海报墙、详情、播放器、档案、收藏追剧、弹幕 | 浏览器完成主要任务及异常恢复 |
| 电视完整体验 | APK、配对、焦点、原生播放、弹幕、续播 | 小米电视实机仅用遥控器完成主要任务 |
| 本机交付 | 原生包、服务管理、备份恢复、诊断说明 | 新安装、升级、恢复和服务退出通过检查 |

四类源、Web 和电视均为首版范围。不得用占位页面、可加载脚本或导入成功代替功能验收。

## 2. 产品与数据

- [ ] 新安装后可从本机创建管理员，添加订阅及多个本地目录。
- [ ] 展示推荐、继续观看、近期热播或近期更新、收藏、追剧和最近加入。
- [ ] 搜索先呈现已有结果，再增量展示在线结果；慢站与失败站不阻塞其他结果。
- [ ] 同名不同年份、电影与剧集不会错误归并；可人工匹配、合并及拆分。
- [ ] 本地与在线版本可在统一详情页选择，保留全部线路及版本差异。
- [ ] 本地扫描读取视频、NFO、海报和字幕，不改变媒体文件与原目录。
- [ ] 源条目消失、目录暂时离线和临时地址过期均保留收藏、追剧和观看历史。
- [ ] 多档案之间数据独立，Web 与电视跨设备同步进度及收藏。
- [ ] 电视配对须经管理员网页批准，普通档案不能执行管理操作。
- [ ] 倍速、音轨字幕、字幕偏移、续播、下一集、手动换线和片头片尾跳过可用。
- [ ] 自动换线只切换确定匹配的单集，明显不同版本有提示。

## 3. 源与运行时

- [ ] CMS、JAR、JS、Python 每类至少两个当时可用的常规点播站点，逐项验证搜索、详情、选集、解析和实际播放。
- [ ] 不同订阅有同名站点时，其配置、脚本、JAR 和状态不会串用。
- [ ] 正确处理相对地址、站点专用 JAR、全局 JAR 及扩展配置。
- [ ] 调用完整播放解析流程，保留必要请求头、Cookie 和有效期信息。
- [ ] 站点能力与错误有明确显示；不兼容、上游失效、缺依赖和登录需求分别记录。
- [ ] worker 超时、错误输出、崩溃和取消可恢复，不影响其他站点与本地播放。
- [ ] 背景刷新不抢占全部播放解析资源；空闲运行时可回收。
- [ ] JVM 宿主具备源码、依赖说明和可复现构建。

## 4. 播放与流传输

| 样本/场景 | 预期 |
|---|---|
| 客户端支持的视频 | 原码直连或代理，不重编码 |
| 仅容器不兼容 | 换封装，复制音视频流 |
| 仅音频不兼容 | 复制视频，仅转音频 |
| 视频不兼容或需要字幕烧录 | 才进入视频转码，并显示原因 |
| 源 403、超时、地址过期 | 重新解析或换线，不直接转码 |
| HDR 且可直通 | 保留原资源，不主动降画质 |
| 播放停止、客户端断开 | 输出任务与临时资源可回收 |
| 转码期间跳转 | 按新时间位置重建输出 |

- [ ] 覆盖 MP4/MKV、HLS、H.264/HEVC、常见音频、多音轨、外挂字幕及可用 HDR 样本。
- [ ] 验证 Range、206、Content-Range、上游跳转和必要请求头。
- [ ] 验证 HLS 主子列表、相对分片、密钥、初始化片段及带签名地址。
- [ ] 硬件转码在实际 Windows 服务运行身份下验证，明确不支持情况及软件兜底。
- [ ] 有限重试后显示具体原因，避免无限切换与重复转码。
- [ ] 服务重启、任务取消和会话过期后没有残留 FFmpeg/worker 或持续增长的临时缓存。

## 5. 弹幕、界面与外部服务

- [ ] 源弹幕、XML/JSON 导入可用；配置弹弹play凭据后支持匹配与加载。
- [ ] 支持手动匹配、时间校准、大小、透明度、密度、区域和关键词过滤。
- [ ] 暂停、倍速与跳转时弹幕正确同步；弹幕不触发视频烧录。
- [ ] TMDB、弹幕服务或单个站点不可用时，其他可用视频仍能播放。
- [ ] 电脑与手机布局可用；缺图、空库、加载、离线和失败状态完整。
- [ ] 小米电视通过方向键、确认和返回完成配对后全部核心操作，返回正确恢复焦点与位置。
- [ ] 实机开启弹幕后，播放和界面仍保持流畅。

- [ ] 本地或可控源连续播放两小时。
- [ ] 两路同时播放时，浏览、搜索和后台更新仍可响应。
- [ ] 验证初次扫描、增量扫描、重复刷新、取消和重启恢复。
- [ ] Windows 前台和服务模式均可启动、停止及正常回收进程。
- [ ] 备份恢复保留账号、档案、收藏、进度、媒体身份和订阅设置。
- [ ] 升级迁移及使用匹配备份回退经过演练。
