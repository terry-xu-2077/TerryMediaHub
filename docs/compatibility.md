# TerryMediaHub 兼容性与当前现状

记录日期：2026-11-04。本文区分会话中已观察到的事实和后续实施目标，尚未进行新服务播放验收。

## 1. 现有项目

| 项目 | 已观察结果 | 边界 |
|---|---|---|
| 现有代码 | Jellyfin 插件，C# / .NET 8 | 独立 Go 服务尚未开发 |
| CMS | 有 JSON/XML 接入代码 | 不代表所有 CMS 站点均已试播 |
| CSP/JAR | 有 JVM 宿主通信及解析代码 | Android 环境依赖可能导致兼容失败 |
| SpiderHost.jar | 已找到，包含 Host 与 Spider 类 | 宿主源码和完整构建流程尚未找到 |
| JS/Python | 现有解析工厂标记为未支持 | 首版新服务要求增加相应 worker |
| 搜索 | 现有统一解析接口没有搜索方法 | 新服务需实现搜索与聚合调度 |
| 多线路 | 现有逻辑选择一条线路 | 新服务需保留全部线路 |
| 流代理 | 已有 UA/Referer、Range、HLS 重写代码 | 必须补充完整上下文和实际传输验证 |
| 入库方式 | `.strm`、NFO、图片与 Jellyfin 扫库 | 新服务使用自己的媒体数据库和播放会话 |

参考位置包括 `src/Jellyfin.Plugin.TerryMediaHub/Sources/`、`Runtime/SpiderHost.cs`、`Api/TerryMediaHubController.cs` 和 `Util/`。根目录 README 的实测描述属于原插件记录，不等于本方案的新服务已验收。

## 2. 订阅配置观察

会话中读取到的默认盒子迷配置包含 91 个站点条目和 15 个解析器，并声明 spider。该计数是当时配置读取结果，不是持续监控，也不是播放成功率。

配置中包含普通点播、JS/Python 脚本、网盘、直播、音乐、配置入口等不同用途。必须按具体能力分类，不能将全部条目当作电影电视剧入库。

| 类型 | 当时配置中的候选 | 后续验证状态 |
|---|---|---|
| CMS | 纯净采集、360资源、量子资源、非凡资源 | 未试播 |
| JAR/CSP | 柠檬、天天、热播等 | 未试播 |
| JS | 极影、猫头鹰、聚合短剧等 | 尚未接入新运行时 |
| Python | 央视栏目、枫叶、木兮等 | 尚未接入新运行时 |
| 网盘/登录 | 网盘配置及多个网盘条目 | 首版不做账号登录链路 |
| 直播/体育/音乐 | 订阅中存在相关条目 | 不纳入首版普通点播验收 |

候选仅表示配置存在，不保证当前可用。实施时需从四类中各选至少两个可用的常规点播样本；脚本协议、依赖及用途必须实际检查。候选失效时记录原因并替换，不以空壳适配通过验收。

## 3. 本机和客户端

| 项目 | 已知信息 | 后续验证 |
|---|---|---|
| 系统 | Windows 10 专业版 64 位 | 服务身份、目录权限、启停及网络访问 |
| CPU/内存 | i3-9100T，约 16 GB | 实测资源占用，不据此预先删减功能 |
| GPU | Intel UHD Graphics 630 | FFmpeg 实际编解码和硬件转码能力 |
| Jellyfin | 用户反馈当前机器运行流畅 | 作为同条件体验对照基线 |
| 电视 | 用户提供小米 HyperOS 3.0.102.0 | 型号、Android API、解码器、APK 安装、遥控与弹幕 |
| Web | 电脑及手机浏览器为目标 | 实际浏览器能力、HLS、字幕和错误恢复 |

HyperOS 版本不直接等同于 Android API 或编码能力，不根据其版本号推断最低系统和直通范围。

此前环境只读检查发现 Node、Python、Java 以及 Jellyfin 的 FFmpeg；PATH 中未发现 Go、Gradle 或 adb。该结果不排除其他目录存在相关工具。本次仅交付文档，没有安装工具链。

## 4. 外部服务

- 元数据默认使用源资料，可选 TMDB 补全；网络、凭据或服务失败不应阻塞浏览与播放。
- 弹幕优先使用源能力及文件导入，弹弹play为可选接入，需要申请和配置应用凭据。
- 现有 JVM 产物作为迁移参考，必须恢复源码、依赖与构建过程后再作为可维护交付。

参考：[TMDB 开发文档](https://developer.themoviedb.org/docs)、[弹弹play 接入说明](https://doc.dandanplay.com/open/)。
